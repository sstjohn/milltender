milltender

A Python daemon that tends a walking treadmill over Bluetooth.

GitHub repository Back to ssj.lol

What it handles

  • Automatic sessions with speed, distance, step counts, and calories.
  • Heart rate from a BLE monitor, plus heart-rate variability (HRV) when the device supplies beat-to-beat RR intervals.
  • FIT export and uploads to Strava and Garmin Connect after a session, when configured.
  • A local dashboard with live charts, speed and start/pause/stop controls, fitness trends, and session history.
  • Interval programs with timed holds, speed ramps, heart-rate holds, and step or distance goals; past sessions can be replayed as programs.
  • Multi-week training plans built from those programs.

Hardware

A treadmill with a FitShow Bluetooth module (advertising as FS-…) and a nearby Mac or Linux computer with Bluetooth and Python 3.11 or later. A Raspberry Pi is suitable. Developed and tested on the LifeSpan TX6 Glow-Up; other FitShow pads are expected to work but may need unit-calibration adjustments.

A BLE heart-rate monitor is optional. For HRV, use a chest strap that provides RR intervals. Devices that broadcast heart rate without RR intervals leave HRV blank.

Getting started

Clone the repository, create a Python virtual environment, and install requirements.txt. Configure .env for your setup, then run python milltender.py and open http://localhost:8321 for the dashboard.

Set MAX_MPH to a safe speed and keep the treadmill remote nearby. See the README for installation, configuration, safety notes, and upload setup.
